# Revisão de vídeos

Página de revisão automática dos shorts de anime 1:1 em 3 idiomas (inglês, alemão e francês).

Acesse: https://jpablopng.github.io/revisao-videos

Arraste os vídeos exportados e a página confere resolução, duração, fps, duração dos takes, faixa preta, mídia repetida, ciclo de transições, cliques e a comparação entre idiomas. Tudo roda no navegador, nenhum vídeo é enviado.
